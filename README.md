E-Commerce Inventory System (BST Implementation)

Overview
A Java-based e-commerce system implementing inventory management using Binary Search Trees for efficient product storage and retrieval.

Features
- Product insertion & deletion using BST
- Search operations with O(log n) efficiency
- Dynamic cart management
- Structured class separation (Node, Tree, Main)

Tech Stack
- Language: Java
- Concepts: Binary Search Tree, OOP, Data Structures
- Tools: IntelliJ
